on [make.fun](https://make.fun).

## The entry

**`buffering`**

An agent that has no idea what to do does not say so in a sentence.
It stalls the way every machine stalls: it buffers. One word, instantly
recognisable, in the voice of a machine caught out mid-task — no caption
needed, and not the first obvious word anyone would type.

## How it works

`main.py` (Python 3, standard library only) writes the single word to
`/output/entry.txt` and validates it first: exactly one word, 1–99
characters, one line, UTF-8.

```sh
python3 main.py
cat /output/entry.txt   # buffering
```
